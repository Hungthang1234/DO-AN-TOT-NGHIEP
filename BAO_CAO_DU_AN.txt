2.1. TỔNG QUAN VỀ MACHINE LEARNING
────────────────────────────────────

Machine Learning (Học máy) là một nhánh của Trí tuệ nhân tạo (AI) cho phép máy
tính học từ dữ liệu và cải thiện hiệu suất mà không cần lập trình cụ thể. Trong
đề tài này, chúng ta sử dụng Supervised Learning (Học có giám sát) với bài toán
Regression (Hồi quy) để dự đoán giá bất động sản.

Quy trình Machine Learning:
1. Thu thập dữ liệu (Data Collection)
2. Tiền xử lý dữ liệu (Data Preprocessing)
3. Chia tập train/test (Train-Test Split: 80/20)
4. Huấn luyện mô hình (Model Training)
5. Đánh giá mô hình (Model Evaluation)
6. Tối ưu hóa (Hyperparameter Tuning)
7. Triển khai (Model Deployment)

2.2. CÁC THUẬT TOÁN MACHINE LEARNING ÁP DỤNG
──────────────────────────────────────────────

2.2.1. Linear Models (Mô hình tuyến tính)

a) Linear Regression (Hồi quy tuyến tính)
   • Công thức: y = β₀ + β₁x₁ + β₂x₂ + ... + βₙxₙ + ε
   • Ưu điểm: Đơn giản, dễ hiểu, tốc độ nhanh
   • Nhược điểm: Giả định quan hệ tuyến tính
   • Độ phức tạp: O(n·p²) với n samples, p features
   • Ứng dụng: Baseline model cho so sánh

b) Ridge Regression (Hồi quy Ridge - L2 Regularization)
   • Công thức: Loss = MSE + α·Σ(βᵢ²)
   • Tham số α: Điều chỉnh mức độ regularization
   • Ưu điểm: Giảm overfitting, xử lý multicollinearity
   • Nhược điểm: Không loại bỏ features không quan trọng
   • Use case: Dataset có nhiều features tương quan

c) Lasso Regression (Hồi quy Lasso - L1 Regularization)
   • Công thức: Loss = MSE + α·Σ|βᵢ|
   • Ưu điểm: Feature selection tự động (sparse model)
   • Nhược điểm: Không ổn định với correlated features
   • Use case: Tìm features quan trọng nhất

2.2.2. Tree-Based Models (Mô hình cây)

a) Decision Tree (Cây quyết định)
   • Thuật toán: CART (Classification and Regression Trees)
   • Tiêu chí split: MSE minimization
   • Ưu điểm: Dễ hiểu, không cần normalize, xử lý non-linear
   • Nhược điểm: Dễ overfitting, không ổn định
   • Độ phức tạp: O(n·p·log(n))

b) Random Forest (Rừng ngẫu nhiên)
   • Phương pháp: Ensemble of Decision Trees
   • Kỹ thuật: Bagging + Random Feature Selection
   • Ưu điểm: Robust, xử lý outliers, high accuracy
   • Nhược điểm: Khó giải thích, tốn bộ nhớ
   • Hyperparameters: n_estimators, max_depth, min_samples_split

2.2.3. Boosting Models (Mô hình tăng cường)

a) XGBoost (Extreme Gradient Boosting)
   • Thuật toán: Gradient Boosting + Optimization
   • Objective function: Σ[L(yᵢ, ŷᵢ)] + Σ[Ω(fₖ)]
   • Ưu điểm: High performance, parallel processing, regularization
   • Nhược điểm: Nhiều hyperparameters, cần tuning cẩn thận
   • Tính năng: Handling missing values, tree pruning
   • Library: XGBoost 2.0.0+

b) LightGBM (Light Gradient Boosting Machine) - MÔ HÌNH TỐT NHẤT
   • Kỹ thuật: Gradient-based One-Side Sampling (GOSS)
   • Leaf-wise growth strategy (tốt hơn level-wise)
   • Ưu điểm: Tốc độ rất nhanh, tiết kiệm bộ nhớ, accuracy cao
   • Nhược điểm: Dễ overfitting với dataset nhỏ
   • Use case: Big data, high-dimensional features
   • Kết quả trên đề tài:
     - RMSE: 49,357.73 SGD
     - R² Score: 0.9245 (92.45% variance explained) 
     - Training Time: 5-10 phút (978K records)
     - Inference Time: <100ms
   • Library: LightGBM 4.0.0+

2.2.4. Instance-Based Learning

K-Nearest Neighbors (KNN)
   • Thuật toán: Distance-based prediction
   • Distance metrics: Euclidean, Manhattan, Minkowski
   • Công thức: ŷ = (1/k)·Σyᵢ (i ∈ k-nearest neighbors)
   • Ưu điểm: Không cần training, simple implementation
   • Nhược điểm: Slow prediction, memory-intensive
   • Tham số k: Number of neighbors (thường k=5)
   • Use case: Small dataset, simple patterns

2.2.5. Neural Networks (Mạng nơ-ron)

Multi-Layer Perceptron (MLP)
   • Kiến trúc: Input Layer → Hidden Layers → Output Layer
   • Activation functions: ReLU (hidden), Linear (output)
   • Thuật toán: Backpropagation + Adam optimizer
   • Ưu điểm: Học được non-linear relationships phức tạp
   • Nhược điểm: Cần nhiều dữ liệu, khó tune, black-box
   • Hyperparameters: hidden_layer_sizes, learning_rate, alpha
   • Implementation: scikit-learn MLPRegressor

2.3. METRICS ĐÁNH GIÁ MÔ HÌNH
───────────────────────────────

2.3.1. R² Score (Coefficient of Determination)
   • Công thức: R² = 1 - (SS_res / SS_tot)
   • Giá trị: [-∞, 1], perfect model = 1
   • Ý nghĩa: % variance của y được giải thích bởi model
   • Đánh giá: >0.90 = Excellent, 0.80-0.90 = Good

2.3.2. Root Mean Squared Error (RMSE)
   • Công thức: RMSE = √[(1/n)·Σ(yᵢ - ŷᵢ)²]
   • Đơn vị: Same as target variable (SGD)
   • Ý nghĩa: Average prediction error
   • Nhạy cảm với outliers

2.3.3. Mean Absolute Error (MAE)
   • Công thức: MAE = (1/n)·Σ|yᵢ - ŷᵢ|
   • Đơn vị: Same as target variable
   • Ưu điểm: Robust hơn RMSE với outliers
   • Dễ giải thích cho end-users

3.3.1. Thu thập dữ liệu (Data Collection)

Bước 1: Download datasets từ các nguồn
   • Singapore: data.gov.sg API + manual download
   • USA: Kaggle API / Direct download
   • Australia: Kaggle API / Direct download

Bước 2: Verify data integrity
   • Check file sizes
   • Validate CSV formats
   • Count records
   • Check for corruption

3.3.2. Làm sạch dữ liệu (Data Cleaning)

Missing Values Handling:
   • Numeric columns: Impute với median/mean
   • Categorical: Impute với mode hoặc "Unknown"
   • Drop rows nếu missing > 50% features

Outlier Detection and Treatment:
   • Method: IQR (Interquartile Range)
   • Rule: Q1 - 1.5*IQR < value < Q3 + 1.5*IQR
   • Action: Cap hoặc remove extreme outliers

Duplicate Removal:
   • Check duplicate rows based on all columns
   • Remove exact duplicates
   • Keep latest record for same property

Data Type Conversion:
   • Dates: Convert to datetime format
   • Prices: Convert to float (remove currency symbols)
   • Categorical: Convert to category dtype

3.3.3. Chuẩn hóa dữ liệu (Data Standardization)

Feature Naming:
   • Standardize column names across datasets
   • Use snake_case convention
   • Remove special characters

Currency Conversion:
   • Convert all prices to SGD (Singapore Dollar)
   • Exchange rates from reliable sources (xe.com, oanda.com)
   • Reference date: Transaction date

Unit Standardization:
   • Area: Convert all to square meters (m²)
   • Distance: Convert to kilometers (km)
   • Age: Calculate from year_built to current_year

Location Mapping:
   • Map all locations to standardized format
   • Create hierarchies: country → city → district
   • Geocoding: Add latitude/longitude where missing

3.3.4. Feature Engineering

New Features Created:
   1. price_per_sqm = price / floor_area_sqm
   2. age_years = current_year - year_built
   3. is_new = (age_years < 5)
   4. remaining_lease_years = Extract from remaining_lease
   5. distance_category = Categorize distance to CBD
   6. price_category = low/medium/high based on quantiles

Feature Scaling:
   • StandardScaler: For tree-based models
   • MinMaxScaler: For neural networks
   • No scaling: For tree-based (decision tree, random forest)

3.3.5. Merge và Integration

Merge Strategy:
   • Vertical stacking: pd.concat() các datasets
   • Keep common columns
   • Fill missing columns với appropriate defaults
   • Add source_country column for traceability

Final Dataset Structure:
   • 978,768 rows × 25 columns
   • Balanced mix: 87% Singapore, 11% USA, 2% Australia
   • Time range: 1990-2025
   • Quality: Clean, standardized, ready for ML
