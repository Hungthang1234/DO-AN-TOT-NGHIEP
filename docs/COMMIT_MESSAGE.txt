## ✨ Train models clean - Tránh overfitting và data leakage

### 🎯 Mục tiêu
Khắc phục vấn đề overfitting (R² = 0.9998) và data leakage từ feature `price_per_m2`

### 🔧 Thay đổi chính

1. **Loại bỏ data leakage**
   - Xóa feature `price_per_m2 = price / area_m2`
   - Model không còn học shortcut, học pattern thật

2. **Anti-overfitting parameters**
   - Decision Tree: max_depth=10, min_samples_split=100
   - Random Forest: max_depth=15, max_features='sqrt'
   - XGBoost: reg_alpha=1.0, reg_lambda=1.0, subsample=0.8
   - LightGBM: reg_alpha=0.5, reg_lambda=0.5

3. **Overfitting detection**
   - Monitor train/test R² gap
   - Gap < 0.02 = Good, Gap > 0.05 = Overfit
