🚀 HOW TO USE:

For Users:
──────────
1. Open web application
2. Look for [🌐 EN] button in top-right corner
3. Click to toggle: EN ↔ VI
4. All text updates instantly
5. Preference saved automatically

For Developers:
───────────────
1. Add translations to static/js/translations.js:
   
   en: { myKey: "English text" }
   vi: { myKey: "Văn bản tiếng Việt" }

2. Use in HTML:
   
   <span data-i18n="myKey">Default text</span>

3. Or in JavaScript:
   
   const text = t('myKey');
