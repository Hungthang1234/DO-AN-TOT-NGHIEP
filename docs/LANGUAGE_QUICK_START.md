# 🌐 Language Selection Feature - Quick Start Guide

## Tính Năng Chọn Ngôn Ngữ - Hướng Dẫn Nhanh

---

## 🎯 What is this? / Đây là gì?

**English:** A new language toggle feature that allows you to switch the entire website between English and Vietnamese instantly!

**Tiếng Việt:** Tính năng chuyển đổi ngôn ngữ mới cho phép bạn chuyển toàn bộ website giữa tiếng Anh và tiếng Việt ngay lập tức!

---

## 🚀 How to Use / Cách Sử Dụng

### Step 1: Open the Application / Bước 1: Mở Ứng Dụng

```bash
# Method 1: Quick Start
cd "D:\Do An Tot Nghiep - Du doan gia bat dong san bang ML va DL\bat_files"
START_WEB.bat

# Method 2: Menu
MENU.bat
# Then choose option [1]
```

### Step 2: Find Language Button / Bước 2: Tìm Nút Ngôn Ngữ

Look at the **top-right corner** of the page header:

```
┌─────────────────────────────────────────────────────┐
│  House Price Prediction & Analytics                │
│                                                     │
│                              [🌐 EN] [🌙 Dark Mode]│
│                                 ↑                   │
│                          Click here! / Nhấn đây!   │
└─────────────────────────────────────────────────────┘
```

### Step 3: Click to Switch / Bước 3: Nhấn Để Chuyển

**First click:** EN → VI (English to Vietnamese)
```
Before: [🌐 EN]
After:  [🌐 VI]
```

**Second click:** VI → EN (Vietnamese to English)
```
Before: [🌐 VI]
After:  [🌐 EN]
```

## ✨ Features / Tính Năng

### 1. **Instant Switch** / **Chuyển Ngay Lập Tức**
- **EN:** No page reload needed! All text updates immediately
- **VI:** Không cần tải lại trang! Tất cả văn bản cập nhật ngay

### 2. **Persistent Preference** / **Lưu Tùy Chọn**
- **EN:** Your choice is saved - next visit uses your preferred language
- **VI:** Lựa chọn được lưu - lần mở sau dùng ngôn ngữ bạn chọn

### 3. **Complete Coverage** / **Bao Phủ Toàn Diện**
- **EN:** All tabs, forms, buttons, messages translate
- **VI:** Tất cả tab, form, nút, thông báo đều được dịch

### 4. **Both Themes** / **Cả Hai Chủ Đề**
- **EN:** Works perfectly with Light Mode and Dark Mode
- **VI:** Hoạt động hoàn hảo với Chế Độ Sáng và Tối

## 🆘 Troubleshooting / Xử Lý Sự Cố

### Problem: Language button not visible
**Solution:** Hard refresh browser (Ctrl+Shift+R)

### Problem: Text not changing
**Solution:** Check browser console (F12) for errors

### Problem: Preference not saving
**Solution:** Enable localStorage in browser settings

### Vấn đề: Nút ngôn ngữ không hiển thị
**Giải pháp:** Tải lại trang mạnh (Ctrl+Shift+R)

### Vấn đề: Văn bản không đổi
**Giải pháp:** Kiểm tra console trình duyệt (F12)

### Vấn đề: Không lưu tùy chọn
**Giải pháp:** Bật localStorage trong cài đặt trình duyệt
