# Utils Directory

Thư mục chứa các utility scripts và helper functions.

## Files

- **check_full_years.py** - Kiểm tra và phân tích dữ liệu năm trong dataset

## Sử dụng

```bash
# Kiểm tra dữ liệu năm
python utils/check_full_years.py
```

## Mục đích

Các script trong thư mục này hỗ trợ:
- Kiểm tra chất lượng dữ liệu
- Phân tích dataset
- Các công cụ helper cho development
